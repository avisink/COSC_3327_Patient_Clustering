# Project rules for Claude Code

## Branch naming

Name every new branch `avisink-<issue number>-<task-name>`, for example `avisink-12-metrics-evaluation`.

If the task isn't linked to a GitHub issue, leave the number out: `avisink-<task-name>`, for example `avisink-metrics-evaluation`.

- `<task-name>` is a short description in lowercase kebab-case (words joined by hyphens).
- Use the issue number only, without a `#`.
